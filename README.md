# X 帖子页 · 前端教学复刻

用于**前端课堂教学**的 X（Twitter）帖子页面复刻：单文件、双击即用、不联网、不引框架 / CDN。
左侧改数据，右侧预览实时变化；配合 `教案.md` 讲清「页面效果 ↔ CSS 实现」的对应关系。

> ⚠️ 页面底部固定声明「教学演示 · 非平台官方页面」，不可关闭。本项目仅用于教学演示，不得冒充真实平台内容。

## 功能

- **实时编辑**：昵称、@Handle、简介、正文、时间、关注 / 粉丝数、回复 / 转推 / 点赞 / 查看 / 书签数，改一处右侧立刻同步
- **主题与响应式**：深色 / 浅色一键切换，880px 断点，手机竖屏可用
- **结构标注**：开关打开后把头像区 / 头部区 / 正文区 / 互动区（含配图区）标成彩色块，配 F12 讲 CSS
- **演示工具**：「全部随机」一次替换 11 个字段（内置数值偏序校验）、「恢复示例」回到稳定状态
- **导出图片**：2 倍分辨率 PNG，可选「帖子卡」/「主页+帖子」范围与 32 / 48 / 64 边距
- **头像三选一**：字母占位 / 本地上传 / 在线生成（DiceBear），不接入真人照片服务
- **配图上传**：本地选图，16:9 裁切，仅在本机读取
- **Handle 打码**：导出截图可选对 `@Handle` 打成马赛克条，**默认关闭**；预览与导出同步，所见即所得
- **翻译帖子卡（v1.1.0 新增）**：现有帖子卡下方追加一张 X 风格「英文 → 中文」卡；英文原文 / 中文译文两栏可实时编辑；GUI 切换「经典手动版（点「翻译帖子」展开译文，标注 Google 翻译）」/「2026 自动版（译文默认显示 + 「显示原文」）」；主题 / 结构标注 / 头像 / 视图切换同步跟随；互动行 6 个操作 + 回复 / 转推 / 点赞 / 查看 / 收藏 5 个数字与左侧输入框实时同步（含「随机 / 恢复示例」）；**不进入导出 PNG，仅用于课堂演示**
- **分组导航与折叠（v1.2.0 新增）**：编辑面板顶部吸顶「共用 / 主页 / 帖子 / 翻译」导航，点一下直达并自动展开；分组可折叠，默认收起两组，另有「全部收起 / 全部展开」一键
- **受限就地编辑（v1.2.0 新增）**：GUI 开关「卡片就地编辑」**默认关闭**；开启后双击帖子正文或翻译卡译文可直接改字，提交后写回左侧输入框、三处视图同步；编辑态不进入导出 PNG
- **窄屏溢出修复（v1.2.1）**：纯追加一条 `@media` 把 `.app` 单列轨道从 `1fr` 改为 `minmax(0, 1fr)`，修掉 375 竖屏自 v1.0.1 起存在的 5px 横向滚动；宽屏布局与导出 PNG 均零变化

双击 `index.html` 即可，无需安装、无需服务器、无需联网。

## 教学用法

`教案.md` 按课拆好，每课含「讲什么 / 对应区域 / 动手练习 / 验收」：

1. 结构与响应式骨架（Grid、sticky、媒体查询）
2. 圆形头像与图片裁切（`object-fit: cover`、`aspect-ratio`）
3. 文本排版、省略与换行（`min-width: 0`、`pre-wrap`）
4. 互动行与数字对齐
5. 主题变量与结构标注
6. 给导出的截图打码（状态该挂在哪）
7. 「不许改旧代码」时怎么接新功能（翻译帖子卡：事件叠加 + MutationObserver）
8. 两种范式：数据驱动 vs 就地编辑（分组导航 / 折叠 / 受限就地编辑）
9. 附：常见坑速查表

课堂建议：全程开着浏览器开发者工具（F12），边改边看，配合「显示结构标注」开关。

## 技术实现

- 原生 HTML / CSS / JS，**单文件**，不引任何框架、CDN、外部字体或图标库
- 本地图片走 `FileReader → data URL`，不上传到任何服务器
- 导出走 `SVG foreignObject → canvas → PNG`，代码内含两种实现方案的对比注释
- 关键教学点均附中文注释；主题变量挂在 `[data-theme]` 上，保证导出克隆的 DOM 里颜色照样继承
- v1.1.0 翻译卡为**纯追加**：新卡是 `#postCard` 的兄弟节点（天然不进导出），旧数据靠事件叠加 + `MutationObserver` 接上，现有 DOM / CSS / JS 一行未改
- v1.1.1 翻译卡互动行的 5 个数字同样靠 `input` 事件叠加同步；「随机 / 恢复示例」直接写 `.value` 不触发 `input`，另叠 `click` + `setTimeout 0` 读新值，仍不改 `render()`
- v1.2.0 导航 / 折叠 / 就地编辑仍是**纯追加**：新 CSS 用 `nv-` / `ie-` 前缀，状态挂在 `body`（导出克隆 DOM 无 body），编辑浮层挂在 `body` 下不进克隆列表；就地编辑提交后 `dispatchEvent(new Event('input'))` 走老通道，`render()` 一行未改
- v1.2.1 修窄屏溢出同样坚持纯追加：新规则是 `@media`，`collectCss()` 会跳过 `MEDIA_RULE`，所以不进导出 SVG；配合 `min-width:0` 挡住 grid item 默认 `min-width:auto` 的二次撑开
- 页面不收集、不回传任何数据
